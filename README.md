# ⚡ AI Prompt Optimizer

Aplicação web que transforma ideias simples de negócios em prompts estruturados de alta performance para Inteligência Artificial.

🔗 **[Acesse o projeto online aqui](https://webdesignermarlon-code.github.io/ai-prompt-optimizer/)**

## 🚀 Tecnologias Utilizadas
* **HTML5**
* **Tailwind CSS**
* **JavaScript (ES6+)**

## 💡 Funcionalidades
* Estruturação automática com definição de persona, passos práticos e métricas de sucesso.
* Interface moderna e responsiva em Dark Mode.
